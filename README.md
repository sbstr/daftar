# Daftar Arabic-First SaaS

## تحديث الإطلاق

أضيفت حزمة إطلاق تجريبي قبل تفعيل البيانات الرسمية:

- لا يتم احتساب ضريبة القيمة المضافة حتى يتم تفعيل `vatRegistrationStatus=registered` مع رقم ضريبي صحيح.
- نقاط الدفع تعمل في وضع `sandbox` تلقائيًا، وتتحول إلى Moyasar عند ضبط `PAYMENT_PROVIDER=moyasar` و`MOYASAR_SECRET_KEY`.
- نقاط واتساب تعمل في وضع تسجيل محلي، وتتحول إلى Meta WhatsApp Cloud API عند ضبط مفاتيح واتساب.
- نقاط ZATCA محمية: يتم حظر report/clearance إذا لم تكن المنشأة مسجلة ضريبيًا.
- أضيفت صفحات `refund.html` و`support.html`.
- أضيفت وثائق `docs/API.md` و`docs/PRODUCTION.md` و`docs/DATABASE.md`.

منصة **Daftar** بتصميم Arabic-first للمنشآت الخدمية الصغيرة في السعودية. المشروع يحتوي على واجهة تسويقية، تجربة تطبيق، وصفحات قانونية وتشغيلية، وBackend محلي كامل للتجربة والتطوير.

## ماذا يحتوي النموذج؟

- لوحة رئيسية عربية بمنطق عملي: اليوم، التحصيل، الضريبة، والتنبيهات.
- تنقل RTL كامل مع القائمة على اليمين.
- واجهة إنشاء فاتورة عربية مع معاينة ضريبة القيمة المضافة.
- تحقق من رقم الجوال السعودي والرقم الضريبي.
- دعم إدخال الأرقام العربية والإنجليزية.
- Smart direction للحقول المختلطة عربي/إنجليزي.
- محرك Daftar Collect بقوالب حسب القطاع.
- قوالب جاهزة للتدريب، الاستشارات، الورش، والمواعيد.
- معاينة رسالة واتساب تتغير حسب بيانات العميل والفاتورة.
- زر نسخ رسالة واتساب.
- خط متابعة للفواتير: أُرسلت، شوهدت، تحتاج تذكير، مدفوعة.
- بحث عربي في العملاء مع تطبيع الهمزات والأرقام.
- تبديل لغة عربي/إنجليزي مع بقاء العربية هي التجربة الأساسية.

## التشغيل كصفحات Static

افتح `index.html` مباشرة في المتصفح. لا يحتاج النموذج إلى تثبيت حزم أو تشغيل خادم.

## التشغيل كمنتج محلي مع Backend

من داخل مجلد المشروع:

```bash
npm start
```

ثم افتح:

```text
http://localhost:4173
```

بيانات الدخول التجريبية للـ API:

```text
owner@daftar.local
Daftar@12345
```

الواجهة في `app.html` تتصل تلقائيًا بالـ Backend عند تشغيله، وإذا لم يكن السيرفر يعمل تستخدم بيانات تجريبية حتى لا تنكسر التجربة.

## ماذا يغطي الـ Backend؟

- مصادقة JWT مبسطة.
- منشآت ومستخدمون.
- عملاء.
- فواتير مع احتساب ضريبة القيمة المضافة.
- روابط دفع placeholder.
- خطط تحصيل وتذكيرات واتساب.
- مدفوعات.
- تقارير Dashboard وVAT.
- بحث عربي.
- سجلات تدقيق.

## قبل الإنتاج الحقيقي

هذا Backend عملي للتطوير والاختبار، لكنه يحتاج قبل الإنتاج إلى PostgreSQL، مزود دفع حقيقي، WhatsApp Business API، مسار امتثال ZATCA، مراجعة قانونية، Rate limiting، واختبارات آلية.
